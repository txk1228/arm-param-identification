# 方法说明：静力学与动力学参数辨识

本仓库算法的技术摘要。英文原文：[`../METHOD.md`](../METHOD.md)

## 整体流程

```text
URDF（教学 7-DoF 或自有机型）
    │
    ├─ 静力学：低速余弦轨迹
    │     Y = [Y_g（RNEA 数值列）| Y_fc]
    │     估计 π_g + 库仑摩擦  →  重力补偿
    │
    └─ 动力学：傅里叶轨迹（解析 q, dq, ddq）
          Y = [Y_dyn（Pinocchio 回归器）| Y_fc | Y_fv]
          估计基惯量参数 + 摩擦  →  力矩前馈

共享后处理：列主元 QR → OLS / Huber-IRLS / 白化鲁棒 WLS
验证：噪声 + 尖峰异常；内点 RMSE；重力补偿检查；
      可选轨迹碰撞回放
```

## 静力学 vs 动力学

| | 静力学 | 动力学 |
|--|--------|--------|
| 适用场景 | 只需低速重力补偿 | 需要惯量 / 高速力矩前馈 |
| 轨迹 | 低速余弦扫关节 | 有限傅里叶级数 |
| 估计量 | 重力相关项 + 库仑摩擦 | 惯量 + 科氏/离心 + 重力 + 库仑/粘性 |
| 关键指标 | 重力补偿误差 | 基参数秩；内点力矩 RMSE |

## 因果链（设计依据）

1. **目标：** 重力补偿 / 力矩前馈需要惯量与摩擦参数 \(π\)，不能只靠 PID 增益。
2. **线性性：** 刚体力矩对惯量参数仿射：\(τ = Y(q,\dot q,\ddot q)\,π\)。静力学（速度、加速度近似为 0）只剩重力 + 库仑摩擦。
3. **构造 \(Y\)：**
   - 静力学：Pinocchio 没有解析 \(Y_g\) → 对各连杆置单位质量/一阶矩，跑 RNEA(\(q,0,0\)) 得到数值列。
   - 动力学：`computeJointTorqueRegressor` + 光滑库仑 + 粘性摩擦列。
4. **QR：** 完整参数向量不可唯一辨识 → 列主元 QR 得到基参数集，并改善条件数。
5. **鲁棒 + 傅里叶：** 傅里叶保证 \(q,\dot q,\ddot q\) 一致且带限；Huber 对大残差降权；白化处理关节异方差；硬阈值剔除尖峰。
6. **用于控制：** \(\hatπ\) → \(τ_g = Y_g(q)\hatπ_g\) 或 \(τ_{ff}=Y(q,\dot q,\ddot q)\hatπ\)。

## FAQ（技术）

**静力学估什么？** 重力相关参数与库仑摩擦。控制器主要做重力补偿时够用。

**为什么用数值 \(Y_g\)？** Pinocchio 不提供解析重力回归器；用单位参数 RNEA 列构造。

**为什么要 QR？** 过参数化 → 最小二乘解不唯一 / 病态。

**OLS 和 robust WLS 差在哪？** OLS 会被力矩尖峰带偏；Huber 降权；白化去掉残差相关/异方差；外环把白化残差过大的样本置零。

**为什么不用随机 \((q,\dot q,\ddot q)\)？** 运动学不一致，真机难跟踪；傅里叶轨迹可执行且频谱可控。

**仿真 vs 真机？** 此处力矩由 URDF 真值 + 噪声合成。真机还有柔性、温度、驱动动力学、传感器偏置。管线可迁移，数字不能直接当精度。

**SDP 可行性？** 可选伪惯量正半定约束（如 cvxpy）。默认关闭；主路径是 QR + robust WLS。
