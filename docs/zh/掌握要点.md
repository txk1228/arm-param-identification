**静力学 vs 动力学（一句话）**

| | 静力学 | 动力学 |
|--|--------|--------|
| 何时用 | 够用重力补偿、低速 | 要惯量/高速前馈 |
| 轨迹 | cosine 慢扫 | 傅里叶（含加速度） |
| 估什么 | 重力项 + 库仑摩擦 | 惯性+科氏+重力+库仑+粘性 |

## 3. 六步因果链（开场 60–90 秒，背熟）

1. **要解决什么**  
   力控需要重力补偿 / 力矩前馈，必须知道杆件惯性与摩擦，不能只调 PID。

2. **为什么能写成最小二乘**  
   刚体力矩对惯性参数仿射：\(τ = Y(q,\dot q,\ddot q)\,π\)。  
   静力学零速零加速时主要是重力 + 库仑摩擦。

3. **Y 怎么来**  
   - 静：Pinocchio 无解析 \(Y_g\) → 对每个杆设单位质量/质心矩，RNEA 数值构造  
   - 动：`computeJointTorqueRegressor` + 平滑库仑 + 粘性列

4. **为什么 QR**  
   满参数不可唯一辨识（运动学约束下线性相关）→ 列主元 QR 取基参数，降病态。

5. **为什么鲁棒 + 傅里叶**  
   - 傅里叶：\(q,\dot q,\ddot q\) 解析一致，低频可执行，激励更充分  
   - Huber 降权大残差；白化处理关节异方差；硬阈值剔尖峰

6. **怎么用到控制**  
   \(\hatπ\) → 实时 \(τ_{g}=Y_g(q)\hatπ_g\) 或 \(τ_{ff}=Y(q,\dot q,\ddot q)\hatπ\)。

## 4. 高频追问：标准答（用自己的话再说一遍）

**Q1 静力学估什么？何时够用？**  
重力相关 + 库仑摩擦。低速、主要补偿重力时够用；要惯量前馈必须上动力学。

**Q2 \(Y_g\) 为什么数值差分？**  
Pinocchio 不直接给重力回归矩阵；逐杆置单位参数跑 RNEA(q,0,0) 得到各列。

**Q3 不 QR 会怎样？**  
过参数化、解不唯一、对噪声敏感，数值上可能炸掉或漂。

**Q4 OLS 和 robust_wls 差别？**  
OLS 被尖峰带偏；Huber 连续降权；白化消除关节残差相关/异方差；外层把白化残差过大的样本权重置零。你对比过：鲁棒后重力补偿从约 0.5+ 降到约 0.01。

**Q5 为什么不用随机 (q,dq,ddq)？**  
点与点不连续、加速度不可积，真机跟不住；傅里叶可执行且频谱可控。

**Q6 仿真和真机差在哪？**  
仿真用 URDF 真值合成 \(τ\) 再加噪声；真机还有柔性、温度、驱动器动态、传感器偏差。辨识流程可迁移，数值不能直接当真机指标。

**Q7 SDP？**  
伪惯量正定 → 质量非负、惯量物理可行。主路径是 QR+WLS；SDP 是可选约束，我复现优先主链路。
